WHAT IS AUTO UPDATER?
---------------------
Auto updater is a feature that allows the application to automatically check for new versions on GitHub, download updates, and install them without the user having to manually download and install new versions.

HOW AUTO UPDATER WORKS
----------------------

1. When the app starts (in packaged mode):
   - The Electron main process automatically checks for updates on GitHub
   - If a new version is found, it notifies the user

2. Manual update check:
   - User goes to Settings → App Update
   - Clicks "Check for Updates" button
   - App checks GitHub for new version
   - Shows result to user

3. Download process:
   - If update is available, user clicks "Download Update"
   - Update downloads in background
   - Progress bar shows download percentage

4. Install process:
   - When download completes, user clicks "Install and Restart"
   - App closes
   - Installer runs automatically
   - App restarts with new version


CHALLENGES FACED AND SOLUTIONS
-------------------------------

Challenge 1: Icon Import Error
PROBLEM: Build failed with error "RotateCounterClockwise is not exported by lucide-react"
CAUSE: The icon name RotateCounterClockwise does not exist in lucide-react library
SOLUTION: Changed RotateCounterClockwise to RotateCcw in two files:
- frontend/src/modules/productPurchases/pages/ProductPurchase.jsx
- frontend/src/modules/orders/pages/OrderHistory.jsx

Challenge 2: GitHub Token Not Set
PROBLEM: Build failed with error "GitHub Personal Access Token is not set"
CAUSE: electron-builder needs a GitHub token to authenticate and create releases
SOLUTION: User needs to:
1. Generate GitHub Personal Access Token with repo scope
2. Set it as environment variable GH_TOKEN
3. Can be set in system environment variables or in .env file

Challenge 3: Backend.exe File Missing
PROBLEM: Warning "file source doesn't exist from=frontend/src/backend.exe"
CAUSE: The electron-builder.yml references backend.exe but it doesn't exist in that location
SOLUTION: This is a warning, not an error. The build still succeeds. The backend.exe needs to be built separately or the path needs to be corrected in electron-builder.yml


GITHUB SETUP REQUIREMENTS
--------------------------

To use auto-update, you need:

1. GitHub Repository: ik-shop-management (already created by you)

2. GitHub Personal Access Token:
   - Go to https://github.com/settings/tokens
   - Click "Generate new token (classic)"
   - Select "repo" scope
   - Generate and copy the token
   - Set as environment variable GH_TOKEN

3. Environment Variable:
   - Set GH_TOKEN=your_token_here
   - Can be set in system environment variables
   - Or in .env file as GH_Token=your_token_here

contextBridge.exposeInMainWorld('electronAPI', {

EXPLANATION:

CODE EXPLANATION - CHECK FOR UPDATES FUNCTION:
----------------------------------------------
const checkForUpdates = async () => {
    if (!window.electronAPI) return;

    setUpdateStatus(prev => ({ ...prev, status: 'checking', message: null }));

    try {
        const result = await window.electronAPI.checkForUpdates();
        
        if (result.success) {
            if (result.updateAvailable) {
                setUpdateStatus({
                    status: 'available',
                    version: result.version,
                    releaseNotes: result.releaseNotes,
                    percent: 0,
                    message: null
                });
            } else {
                setUpdateStatus({
                    status: 'not-available',
                    version: null,
                    releaseNotes: null,
                    percent: 0,
                    message: 'You are using the latest version'
                });
            }
        } else {
            setUpdateStatus({
                status: 'error',
                version: null,
                releaseNotes: null,
                percent: 0,
                message: result.error || 'Failed to check for updates'
            });
        }
    } catch (error) {
        setUpdateStatus({
            status: 'error',
            version: null,
            releaseNotes: null,
            percent: 0,
            message: 'Failed to check for updates'
        });
    }
};

EXPLANATION:
------------
- if (!window.electronAPI) return;
  Check if the Electron API is available (only works in desktop app, not web browser)
  
- setUpdateStatus(prev => ({ ...prev, status: 'checking', message: null }));
  Change status to 'checking' to show the user we're looking for updates
  
- const result = await window.electronAPI.checkForUpdates();
  Call the Electron function to check GitHub for updates
  Wait for the result
  
- if (result.success && result.updateAvailable)
  If check succeeded and update is available, show the new version info
  
- else if (result.success && !result.updateAvailable)
  If check succeeded but no update, tell user they have latest version
  
- else
  If check failed, show error message
